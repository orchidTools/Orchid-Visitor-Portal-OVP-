# ORCHID VISITOR PORTAL (OVP) — PROJECT OVERVIEW

---

## 1. EXECUTIVE SUMMARY
The Orchid Visitor Portal is a modern, secure web-based platform designed to manage and track visitor information efficiently. It streamlines the visitor registration process, provides administrative oversight, and maintains a comprehensive audit trail of all system activities for compliance and reporting purposes.

---

## 2. KEY FEATURES & CAPABILITIES
- **Visitor Registration System**: Simple, user-friendly online form enabling visitors to submit their details including name, contact information, nationality, and relevant reference partners
- **Multi-Role Access Control**: Separate secure login portals for administrators and sales teams with role-based permissions and activity logging
- **Administrative Dashboard**: Complete oversight of all visitor records with ability to view, edit, and manage visitor information with full audit documentation
- **Real-Time Activity Tracking**: Automatic logging of all user actions including login history, data access, modifications, and reason tracking for data retrieval to ensure transparency and accountability

---

## 3. USER GROUPS & BENEFITS
| User Type | Purpose | Benefits |
|-----------|---------|----------|
| **Visitors** | Submit personal & professional information | Quick, hassle-free registration; secure data handling |
| **Sales Team** | Access & manage visitor records; track interactions | Improved customer relationship management; access audit trail |
| **Administrators** | System management & oversight | Complete control; full visibility of operations; compliance reporting |

---

## 4. TECHNICAL FOUNDATION & DEPLOYMENT
- **Infrastructure**: Cloud-based system with secure Firebase database backend ensuring 24/7 availability
- **Accessibility**: User-friendly web platform deployable on multiple servers (Netlify, Railway) for optimal performance
- **Security**: CORS-protected, role-based authentication, encrypted data transmission, and comprehensive activity logs
- **Scalability**: Built for growth with ability to handle increased data volume and user base without performance degradation
